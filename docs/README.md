# Документация по проекту Geometric lib

## Назначение проекта: вычисление площади и периметра простейших геометрических фигур

## Функции

### `area(a,h)`

**Файл:** [triangle.py]
**Назначение:** вычисляет площадь треугольника по основанию и высоте, проведенной к этому основанию.

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | `float` | длина основания (стороны) треугольника |
| `h` | `float` | Длина высоты треугольника, проведеннойк стороне а |

#### Возвращаемое значение

| Тип | Описание |
|-----|----------|
| `float` | Площадь треугольника, равная `a*h/2` |

**Пример вызова функции**
```python
res = area(1,2)
print(res) #1
```

### `perimeter(a, b, c)`

**Файл:** [triangle.py]
**Назначение:** вычисляет периметр треугольника по трём его сторонам.

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `a` | `float` | Длина первой стороны треугольника |
| `b` | `float` | Длина второй стороны треугольника |
| `c` | `float` | Длина третьей стороны треугольника |

#### Возвращаемое значение

| Тип | Описание |
|-----|----------|
| `float` | Периметр треугольника, равный `a + b + c` |

**Примеры вызова функции**

```python
res = perimeter(1,2,3)
print(res) # 6
```

### `perimeter(a, b)`

### `area(r)`

**Файл:** [circle.py]
**Назначение:** вычисляет площадь круга по его радиусу

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `float` | Длина радиуса окружности |

#### Возвращаемое значение

| Тип | Описание |
|-----|----------|
| `float` | Площадь круга, равная `math.pi * r * r` |

**Примеры вызова функции**

```python
res = area(2)
print(res) # 12,56
```


### `perimeter(r)`

**Файл:** [circle.py]
**Назначение:** вычисляет длину окружности по её радиусу

#### Параметры

| Имя | Тип | Описание |
|-----|-----|----------|
| `r` | `float` | Длина радиуса окружности |
#### Возвращаемое значение

| Тип | Описание |
|-----|----------|
| `float` | Длина окружности , равная `2 * math.pi * r ` |

**Примеры вызова функции**

```python
res = area(2)
print(res) # 12,56
```



# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
